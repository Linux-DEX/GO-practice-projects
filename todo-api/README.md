
# 📝 ToDo API with Go, Gorilla Mux, and MongoDB

This is a simple RESTful API built with **Go**, **Gorilla Mux** for routing, and **MongoDB** for data persistence. It allows you to create, list, and delete todo items.

## 📁 Project Structure

.
├── main.go          # Application entry point
├── go.mod           # Module dependencies
└── README.md        # Project documentation


## 🧩 Packages Used

| Package                              | Purpose |
|--------------------------------------|---------|
| `net/http`                           | Build the HTTP server |
| `github.com/gorilla/mux`            | Handle routing (GET, POST, DELETE endpoints) |
| `go.mongodb.org/mongo-driver/mongo` | Connect and interact with MongoDB |
| `go.mongodb.org/mongo-driver/bson`  | Work with BSON (MongoDB documents) |
| `encoding/json`                     | Handle JSON encoding/decoding |
| `context` and `time`                | Manage request timeouts and background context |

## 🔧 MongoDB Connection

The function responsible for connecting to MongoDB is:

```go
func connectDB() *mongo.Collection
```

### Explanation:
- Uses `mongo.NewClient()` to create a client.
- Connects to `mongodb://localhost:27017`.
- Selects the database `tododb` and collection `todos`.
- Returns a handle to the collection which is stored in a global variable:  
  `var todoCollection *mongo.Collection`.

## 📦 ToDo Struct

The `Todo` struct defines the schema of a single todo item:

```go
type Todo struct {
    ID   primitive.ObjectID `json:"id,omitempty" bson:"_id,omitempty"`
    Task string             `json:"task" bson:"task"`
    Done bool               `json:"done" bson:"done"`
}
```

### 🧠 Explanation:

- `ID` is automatically generated by MongoDB (as `_id`) and is omitted in input JSON.
- `Task` is the name/description of the todo.
- `Done` is a boolean flag (true/false) indicating completion.

## 📬 API Endpoints

### 🔍 Get All Todos

**GET** `/todos`  
Returns a list of all todo items.

```bash
http GET http://localhost:8000/todos
```

### ➕ Create a New Todo

**POST** `/todos`  
Creates a new todo item.

```bash
http POST http://localhost:8000/todos task="Buy milk" done:=false
```


### ❌ Delete a Todo

**DELETE** `/todos/{id}`  
Deletes a todo by its MongoDB ObjectID.

```bash
http DELETE http://localhost:8000/todos/<id>
```

Replace `<id>` with the actual ID returned from the GET/POST response.


## 🚀 Running the Server

1. Make sure MongoDB is running (`localhost:27017`).
2. Install dependencies:

```bash
go mod tidy
```

3. Run the app:

```bash
go run main.go
```

4. Visit:  
   [http://localhost:8000/todos](http://localhost:8000/todos)
